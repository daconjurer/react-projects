React projects
===============

So, I am learning React now. The long term plan is to become a fullstack engineer using Rust,
and while I work on that I also need enough knowledge about other frontend technology and
frameworks to build a more informed opinion.

This repo documents my progress, the idea is to push myself to learn more and quicker by
making it public. I am not new to web and have done Typescript for backend software, I have
been part of teams that do frontend software engineering too. I have just never done production
frontend from scratch myself (yet) and hopefully this will change soon!
